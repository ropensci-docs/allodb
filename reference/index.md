# Package index

## Functions

- [`est_params()`](https://docs.ropensci.org/allodb/reference/est_params.md)
  : Calibrate new allometric equations

- [`get_biomass()`](https://docs.ropensci.org/allodb/reference/get_biomass.md)
  : Compute tree aboveground biomass (AGB) based on allometric equations

- [`illustrate_allodb()`](https://docs.ropensci.org/allodb/reference/illustrate_allodb.md)
  :

  Illustrate the resampling of AGB values used in *allodb*

- [`new_equations()`](https://docs.ropensci.org/allodb/reference/new_equations.md)
  : Modify the original equation table

- [`resample_agb()`](https://docs.ropensci.org/allodb/reference/resample_agb.md)
  :

  Resample *allodb* equations to calibrate new allometries

- [`weight_allom()`](https://docs.ropensci.org/allodb/reference/weight_allom.md)
  : Attribute weights to equations

## Database datasets

- [`equations`](https://docs.ropensci.org/allodb/reference/equations.md)
  [`equations_metadata`](https://docs.ropensci.org/allodb/reference/equations.md)
  : Tables of allometric equations and associated metadata
- [`missing_values`](https://docs.ropensci.org/allodb/reference/missing_values.md)
  : Explanations of missing values codes
- [`references`](https://docs.ropensci.org/allodb/reference/references.md)
  [`references_metadata`](https://docs.ropensci.org/allodb/reference/references.md)
  : Equation references and associated metadata
- [`sites_info`](https://docs.ropensci.org/allodb/reference/sites_info.md)
  : ForestGEO sites used in allodb
- [`sitespecies`](https://docs.ropensci.org/allodb/reference/sitespecies.md)
  [`sitespecies_metadata`](https://docs.ropensci.org/allodb/reference/sitespecies.md)
  : Sites and tree species used in allodb and associated metadata

## Other datasets

- [`genus_family`](https://docs.ropensci.org/allodb/reference/genus_family.md)
  : Genus and family table for selected ForestGEO sites
- [`gymno_genus`](https://docs.ropensci.org/allodb/reference/gymno_genus.md)
  : Gymnosperms identified in selected ForestGEO sites
- [`koppenMatrix`](https://docs.ropensci.org/allodb/reference/koppenMatrix.md)
  : Koppen climate classification matrix
- [`scbi_stem1`](https://docs.ropensci.org/allodb/reference/scbi_stem1.md)
  : Tree census data from SCBI ForestGEO plot
- [`shrub_species`](https://docs.ropensci.org/allodb/reference/shrub_species.md)
  : Shrub species identified in selected ForestGEO sites
